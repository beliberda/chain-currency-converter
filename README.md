# Конвертер валют

Простое веб-приложение (PWA) для конвертации валют: быстрая конвертация суммы, ручная правка курса и сравнение цепочек обмена (например, RUB → USD → VND) с прямым обменом.

Никакого бэкенда — статический сайт на чистом HTML/CSS/JS, который можно открыть локально или задеплоить как обычные статические файлы.

## Возможности

- **Быстрая конвертация** — сумма, выбор валют "из/в", кнопка обмена местами.
- **Ручная правка курса** — курс, полученный из API, можно поправить вручную и сбросить обратно к официальному.
- **Цепочки обмена** — постройка нескольких цепочек через промежуточные валюты и сравнение итогового результата с прямым обменом. Курс правится вручную на каждом шаге.
- **PWA** — манифест, иконки, офлайн-кеш через service worker (`sw.js`).
- Курсы валют берутся с [exchangerate-api.com](https://www.exchangerate-api.com) (open access), обновляются раз в сутки.

## Структура проекта

```
index.html               точка входа
manifest.webmanifest      PWA-манифест
sw.js                      service worker (офлайн-кеш)
nginx.conf                 пример конфигурации nginx для деплоя
assets/
  css/style.css            стили
  js/index.js              логика конвертера
  js/register-sw.js         регистрация service worker
  icons/                    иконки приложения
```

## Запуск локально

Открыть `index.html` в браузере, либо поднять любой статический сервер, например:

```bash
npx serve .
```

Service worker и запрос курсов валют требуют HTTP(S)-контекста, поэтому открытие файла напрямую через `file://` может работать с ограничениями (в частности, для запросов к API современные браузеры iOS корректно работают только по `https`).

## Деплой

Проект — статические файлы, поэтому достаточно скопировать `index.html`, `manifest.webmanifest`, `sw.js` и папку `assets/` на любой статический хостинг или веб-сервер.

Пример конфигурации для nginx с корректным кешированием (HTML и service worker не кешируются, статические ассеты — кешируются агрессивно) есть в [`nginx.conf`](nginx.conf).
